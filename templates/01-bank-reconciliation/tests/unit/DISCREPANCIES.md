# Unit-test discrepancies (append-only)

Fixture / CASES expectations that contradict the DESIGN.md pseudocode, and decisions taken where DESIGN.md left a choice open. The code follows the pseudocode; the discrepancy is recorded here for P3 / the DESIGN owner.

## match_invoices.js (Match Invoices) — 2026-09-23

- **T07 / R18 note (open decision in DESIGN, resolved here)**: the §6.7 pseudocode increments `summary.a` / `b` / `c` for rows re-evaluated on the schedule run as well, so R18 would title `処理 0件｜自動消込 1｜要確認 0｜未消込 3`, contradicting D11 (`n = A + B + C`, new rows only, re-matches counted in `rematched`). DECISION taken in `code/match_invoices.js` (`apply`): `a` / `b` / `c` count NEW transactions only (so `n = a + b + c` always holds); an existing unmatched/ambiguous row that becomes matched is counted only in `rematched` and listed in `auto` / `needs_review`; an existing row that stays unmatched/ambiguous is written back and listed in `unmatched` / `ambiguous` only when its status or `suggested_invoice_ids` changed (D10), otherwise it is neither written nor listed. R18 therefore yields `n=0, a=0, b=0, c=0, rematched=1` with the A-11 detail line under `auto`; R19 yields the summary only. To be copied to `ASSUMPTIONS.md` by the P2 integrator (CASES T07 asks for it there).
- **`$now` instead of `DateTime.now()`**: `Match Invoices` takes the run time from `$now.setZone(cfg.TZ)` (same value inside n8n, A12) so that `summary.date` / `imported_at` are deterministic under `run-code-node.mjs`. Not a behavioural difference.
- **`FEE_SET` coercion**: `cfg.FEE_SET` values are passed through `num()` before `includes(fee)` so a buyer who types `"220"` still gets rule 3a. Superset of the pseudocode.
- No fixture expectation contradicted the pseudocode: bank_A (R01–R06, summary `n=11,a=4,b=3,c=4`), bank_B (R13), mails (R10), R09, R14-a/b, R18, R19, R23 all reproduce `fixtures/README.md` / `tests/CASES.md` exactly.

## P2 review fixes — 2026-09-23 (DESIGN D31–D33 added; §3.2 / §3.4 / §6.2 / §6.4 / §6.7 / §8.1 / §8.2 / D22 amended)
